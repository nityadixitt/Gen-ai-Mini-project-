
# Fitness Routine Planner

## Problem Statement
Creating a weekly fitness routine can be difficult for beginners.
This application generates a simple home workout plan based on
the user's fitness goal, fitness level, available time, and equipment.

## Features
- Weekly workout schedule
- Personalized fitness goals
- Beginner, intermediate, and advanced levels
- Exercise sets and repetitions
- Rest days and safety instructions
- AI-generated workout plans using Gemini

## Technologies Used
- Python
- Gradio
- Google Gemini API

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the application:

python app.py

Enter a Gemini API key in the application to generate a workout plan.
